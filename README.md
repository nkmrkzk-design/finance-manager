# カード・銀行・SIM管理ツール

クレジットカード等(`card-manager`)、その引き落とし先の銀行口座(`bank-manager`)、通信回線(SIM)契約(`sim-manager`)を1つのアプリにまとめ、タブ1タップで画面を切り替えられるようにしたツールです。ビルド不要のオフラインWebアプリ(PWA)です。

**公開URL: https://nkmrkzk-design.github.io/finance-manager/**

このリポジトリ(`claude_main`)にはアプリのソースコードのみを置いています。GitHub Pagesはプライベートリポジトリでは無料プランで使えないため、実際にホスティングしているのは別の公開リポジトリ [`nkmrkzk-design/finance-manager`](https://github.com/nkmrkzk-design/finance-manager) です。コードを更新する場合は、このフォルダの変更を`finance-manager`リポジトリ側にも反映してください。

`card-manager`・`bank-manager`・`sim-manager`は元のスタンドアロン版として引き続き利用できますが、SIM回線データは今後この統合アプリ側で一元管理する運用とし、`sim-manager`単体版は更新しません(二重管理を避けるため)。

## 画面構成

ヘッダーの「💳 カード管理」「🏦 銀行管理」「📱 SIM管理」タブをタップすると、1タップで画面が切り替わります(画面ごとにヘッダー色も変わります)。

### 💳 カード管理画面
`card-manager`と同じ項目を管理できます(カード名称・種別・国際ブランド・還元率・年会費・カード利用枠・締め日/引落日・カードごとの固定支払いなど)。

**追加項目:** 「紐づける銀行」— クレジット/ETCカードの引き落とし先を、銀行管理で登録した銀行から選択できます。この紐づけが、固定支払いを銀行管理側へ反映する際に使われます。

### 🏦 銀行管理画面
`bank-manager`と同じ項目を管理できます(銀行名・支店・口座番号・種別、引き落としのサービス名・用途・引き落とし日・金額・解約予定など)。

### 📱 SIM管理画面
`sim-manager`と同じ項目を管理できます(ブランド名・通信回線の種別・回線キャリア・契約日・新規/MNP・契約回数・解約情報・審査NG情報・料金/データ量・SIM種別・端末情報・キャンペーン情報など)。契約日から180日(6ヶ月)経過しているか・次回MNP可能日・実質コスパ(円/GB)・審査NGからの経過月数・割引終了後の値上げ警告は自動計算されます。

**追加項目:** 「支払いカード」— `sim-manager`単体版では自由入力でしたが、この統合アプリではカード管理で登録したカードから選択する形式になっています(銀行の紐づけと同じパターン)。紐づいている回線は一覧画面に「💳 カード名」のバッジで表示されます。

## カードの固定支払いを銀行管理へ反映する

銀行管理画面の「🔗 カードの固定支払いを反映」ボタンを押すと、カード管理側で登録した固定支払いが、銀行管理側の引き落とし一覧に自動で追加されます。

- 対象になるのは「紐づける銀行」が設定されているカードの固定支払いのみです。未設定のカードがある場合は、反映後にアラートで一覧表示されます。カードの編集画面で銀行を設定してから、もう一度反映してください。
- 引き落とし日は、カードの「引落日」がそのまま使われます。
- 利用用途は「その他」、解約予定は「なし」で仮登録されます。実際の内容に応じて、銀行管理画面から個別に編集してください(反映ボタンを再度押しても、一度手動編集した用途・解約予定・メモは上書きされません)。
- 反映済みの引き落としには「🔗 カード連携」のバッジが付きます。
- 何度反映しても重複登録はされません(同じ固定支払いに対応する引き落としが更新されるだけです)。

## 既存アプリのデータを読み込む

### カード管理
すでに`card-manager`アプリにカード情報を入力済みの場合、カード管理画面の「🗂 既存のカード管理アプリのデータを読み込む」から、`card-manager`でエクスポートしたJSONファイルをそのまま読み込めます。

- カードと固定支払いのデータのみが上書きされます。銀行・SIM管理側のデータは影響を受けません。
- 読み込んだカードは「紐づける銀行」が未設定の状態になるため、銀行への反映を使う場合は、それぞれのカードで銀行を設定してください。

### SIM管理
すでに`sim-manager`アプリに回線情報を入力済みの場合、SIM管理画面の「🗂 既存のSIM管理アプリのデータを読み込む」から、`sim-manager`でエクスポートしたJSONファイルをそのまま読み込めます。

- SIM回線のデータのみが上書きされます。カード・銀行管理側のデータは影響を受けません。
- `sim-manager`単体版の「支払いクレジットカード名称」(自由入力)は、この統合アプリの「支払いカード」(カード選択式)とは形式が異なるため自動では紐づきません。旧欄の内容は各回線の備考欄に「旧支払いカード欄: ○○」として自動的に転記されるので、必要な回線はカード管理で登録後、SIM管理の編集画面から改めて「支払いカード」を設定してください。

## データの保存・バックアップ

- データはブラウザの`localStorage`に自動保存されます。
- 「JSONエクスポート」「JSONインポート」は、カード・銀行・SIM・固定支払い・引き落としをすべて含むフルバックアップです。複数端末で同期する場合は、この機能でファイルを転送してください。
- 「CSV出力」は、表示中の画面(カード管理 / 銀行管理 / SIM管理)に応じて、それぞれの一覧をCSVで書き出します(Excel等での確認用。インポートには使えません)。

## スマホのホーム画面に追加する(アプリのように使う)

### iPhone (Safari)
1. Safariで公開URLを開く
2. 共有ボタン(四角から矢印が出ているアイコン)をタップ
3. 「ホーム画面に追加」を選択

### Android (Chrome)
1. Chromeで公開URLを開く
2. 右上の「⋮」メニューをタップ
3. 「アプリをインストール」または「ホーム画面に追加」を選択

## 複数端末で使う場合の注意

このツールはサーバーを持たず、データは各端末のブラウザ内だけに保存されます。複数端末で同じデータを使いたい場合は、「JSONエクスポート」でバックアップし、他端末で「JSONインポート」してください。

## データの取り扱いについて(重要)

- カード情報・銀行口座情報・電話番号やSIMカード番号などは機微な情報です。エクスポートしたJSON/CSVファイルはこのリポジトリにはコミットしないでください(`.gitignore`で`finance-manager/exports/`を除外済みです)。
- バックアップファイルは、パスワード管理ツールやご自身が信頼できる安全な場所に保管してください。
