# カード・銀行管理ツール

クレジットカード等(`card-manager`)と、その引き落とし先の銀行口座(`bank-manager`)を1つのアプリにまとめ、タブ1タップで画面を切り替えられるようにしたツールです。ビルド不要のオフラインWebアプリ(PWA)です。

**公開URL: https://nkmrkzk-design.github.io/finance-manager/**

このリポジトリ(`claude_main`)にはアプリのソースコードのみを置いています。GitHub Pagesはプライベートリポジトリでは無料プランで使えないため、実際にホスティングしているのは別の公開リポジトリ [`nkmrkzk-design/finance-manager`](https://github.com/nkmrkzk-design/finance-manager) です。コードを更新する場合は、このフォルダの変更を`finance-manager`リポジトリ側にも反映してください。

`card-manager`・`bank-manager`は元のスタンドアロン版として引き続き利用できます。このアプリはそれらを1つに統合した3つ目のアプリです(データは別管理のため、それぞれ個別に入力/インポートが必要です)。

## 画面構成

ヘッダーの「💳 カード管理」「🏦 銀行管理」タブをタップすると、1タップで画面が切り替わります(画面ごとにヘッダー色も変わります)。

### 💳 カード管理画面
`card-manager`と同じ項目を管理できます(カード名称・種別・国際ブランド・還元率・年会費・カード利用枠・締め日/引落日・カードごとの固定支払いなど)。

**追加項目:** 「紐づける銀行」— クレジット/ETCカードの引き落とし先を、銀行管理で登録した銀行から選択できます。この紐づけが、固定支払いを銀行管理側へ反映する際に使われます。

### 🏦 銀行管理画面
`bank-manager`と同じ項目を管理できます(銀行名・支店・口座番号・種別、引き落としのサービス名・用途・引き落とし日・金額・解約予定など)。

## カードの固定支払いを銀行管理へ反映する

銀行管理画面の「🔗 カードの固定支払いを反映」ボタンを押すと、カード管理側で登録した固定支払いが、銀行管理側の引き落とし一覧に自動で追加されます。

- 対象になるのは「紐づける銀行」が設定されているカードの固定支払いのみです。未設定のカードがある場合は、反映後にアラートで一覧表示されます。カードの編集画面で銀行を設定してから、もう一度反映してください。
- 引き落とし日は、カードの「引落日」がそのまま使われます。
- 利用用途は「その他」、解約予定は「なし」で仮登録されます。実際の内容に応じて、銀行管理画面から個別に編集してください(反映ボタンを再度押しても、一度手動編集した用途・解約予定・メモは上書きされません)。
- 反映済みの引き落としには「🔗 カード連携」のバッジが付きます。
- 何度反映しても重複登録はされません(同じ固定支払いに対応する引き落としが更新されるだけです)。

## 既存のカード管理アプリのデータを読み込む

すでに`card-manager`アプリにカード情報を入力済みの場合、カード管理画面の「🗂 既存のカード管理アプリのデータを読み込む」から、`card-manager`でエクスポートしたJSONファイルをそのまま読み込めます。

- カードと固定支払いのデータのみが上書きされます。銀行管理側のデータ(銀行・引き落とし)は影響を受けません。
- 読み込んだカードは「紐づける銀行」が未設定の状態になるため、銀行への反映を使う場合は、それぞれのカードで銀行を設定してください。

## データの保存・バックアップ

- データはブラウザの`localStorage`に自動保存されます。
- 「JSONエクスポート」「JSONインポート」は、カード・銀行・固定支払い・引き落としをすべて含むフルバックアップです。複数端末で同期する場合は、この機能でファイルを転送してください。
- 「CSV出力」は、表示中の画面(カード管理 / 銀行管理)に応じて、カード一覧または引き落とし一覧をCSVで書き出します(Excel等での確認用。インポートには使えません)。

## スマホのホーム画面に追加する(アプリのように使う)

### iPhone (Safari)
1. Safariで公開URLを開く
2. 共有ボタン(四角から矢印が出ているアイコン)をタップ
3. 「ホーム画面に追加」を選択

### Android (Chrome)
1. Chromeで公開URLを開く
2. 右上の「⋮」メニューをタップ
3. 「アプリをインストール」または「ホーム画面に追加」を選択

## 複数端末で使う場合の注意

このツールはサーバーを持たず、データは各端末のブラウザ内だけに保存されます。複数端末で同じデータを使いたい場合は、「JSONエクスポート」でバックアップし、他端末で「JSONインポート」してください。

## データの取り扱いについて(重要)

- カード情報・銀行口座情報などは機微な情報です。エクスポートしたJSON/CSVファイルはこのリポジトリにはコミットしないでください(`.gitignore`で`finance-manager/exports/`を除外済みです)。
- バックアップファイルは、パスワード管理ツールやご自身が信頼できる安全な場所に保管してください。
